# Study-agent

一款帮助学习的agent

面向计算机学习者的学习辅助 Agent，计划实现“提问 → 判断 → 搜索 → 阅读正文 → 整理证据 → 回答并引用”的流程。

## 当前状态

项目处于设计阶段，尚未实现应用代码，暂无可运行的服务或测试。

- [项目开发约定](AGENTS.md)

## 开发环境

约定使用 Python 3.11，当前本机解释器为 `D:/codex/.env/new_agent/python.exe`。后续实现时补充依赖和启动命令。

密钥通过环境变量配置；不提交 `.env`、虚拟环境或日志。
