# V4 实现与验收记录

日期：2026-10-02。实施目录：`D:/codex/Study-agent`。本文保留 V1/V2/V3 验收历史，不替换旧记录。

## 已实现范围

论文模式默认关闭；开启并选定单篇文本型 PDF 后自动进行全文快照、分批证据卡和简明导读。深入追问、自测、加入笔记、笔记编辑/Markdown 下载、固定版本 PPT 大纲与 PPTX 导出均需主动操作。模式关闭后仍可回看和导出已保存内容。

任务具备容量、时间和调用预算、模式版本复核、取消、重启中断、事件持久化与 SSE 回放。论文页码和摘录绑定实际读取的快照；向量检索限定当前文件，外部补充需要独立联网许可。

首期快照文本块和产物证据以结构化 JSON 保存，未建立技术设计草案中的独立 `paper_blocks` / `artifact_evidence` 表。追问、来源查询、版本隔离仍由服务校验，不影响当前功能接口。原文件上传仍沿用 V2 同步入库流程。
