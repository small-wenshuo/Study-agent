# 多用户隔离验收记录（2026-10-13）

## 范围

匿名 `/api/sessions`、知识库与记忆曾不要求登录，导致公网访客可看到同一组资料。修复后服务端要求登录，并对会话、记忆、知识库及文件、论文学习记录、任务事件与 SSE、产物、笔记、导出逐层校验归属。新账号的长期记忆使用独立向量集合，旧管理员继续使用原集合。旧业务记录在首次启动时迁为 `legacy-admin`；只有首次管理员继承。

## 已验证

- 匿名访问私人 API 返回 401；已知其他用户的资源 ID 返回 404；跨来源修改被拒绝。
- 两个账号使用真实 HTTP Cookie、SQLite、Chroma 和本地 PDF 测试资料，覆盖历史列表、直接 ID、文件、论文模式、任务事件、笔记和导出路径。
- 公网明文 HTTP 登录返回 403；退出立即吊销服务器会话。
- 全套离线测试执行：`D:/codex/.env/new_agent/python.exe -m unittest discover -q`，91 项通过。测试模型与 Embedding 为模拟服务，不能代表真实提供商。
- Edge 无头浏览器在隔离的本机服务器上验证：登录、退出、切换账号、隐藏未登录页面内容、刷新后恢复本账号会话；检查到的页面脚本错误为零。退出响应长度异常已在复测前修复。
